# Forever Warlock BiS

Best-in-slot gear lists for Warlocks in World of Warcraft Forever, one page per content phase.

**Live page:** https://xnwlk.github.io/BIS/

## Phase 1: pre-raid

A realistic, all-blue pre-raid set for each Warlock build: no raid drops, no epics and no long reputation grinds, picked
item by item from a full search of everything in Phase 1. Every slot shows its Phase 1 enchant.

Click a slot to see two other options down the middle of the character sheet:

- **▲ Upgrade**: the best piece that beats the main one, whatever it takes (epics, crafted gear, reputation rewards, the
  two-hander with the +65 Spell Power enchant), with the DPS it adds and what it costs.
- **▼ Alternative**: the best piece close to the main one that is not epic, crafted, reputation or PvP, with the DPS it
  costs.

Hover an item for its in-game tooltip (on a phone, the first tap shows it); click an item or enchant to open it on
Wowhead. **All builds** shows every build's list side by side.

Each build's DPS comes from [Xn's Forever Warlock Sim](https://xnwlk.github.io/WarlockSIM/) with its own list and enchants,
an ideal Phase 1 raid (full raid buffs, flask, elixirs, food, weapon oil, potion, rune) and a 3-minute boss fight. Every
▲ / ▼ number is a sim run with only that slot swapped. The same lists load into the sim's gear builder (quick setup:
Realistic Pre-BiS).
