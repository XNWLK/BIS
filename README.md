# Forever Warlock BiS

Best-in-slot gear lists for Warlocks in World of Warcraft Forever, one page per content phase.

**Live page:** https://xnwlk.github.io/BIS/

## Phase 1: pre-raid

A realistic pre-raid set for each Warlock build: no raid drops and no long reputation grinds, picked item by item from a
full search of everything that drops in Phase 1. Every slot shows its Phase 1 enchant. Hover an item (or tap it on a phone)
for its in-game tooltip; a second tap opens it on Wowhead.

Each build's DPS comes from [Xn's Forever Warlock Sim](https://xnwlk.github.io/WarlockSIM/) with its own list and enchants,
an ideal Phase 1 raid (full raid buffs, flask, elixirs, food, weapon oil, potion, rune) and a 3-minute boss fight. The same
lists load into the sim's gear builder (quick setup: Pre-BiS).

## Later phases

Each new phase gets its own list here when it opens.
